# Day 24 challenge — Java File Handling

Read the supplied configuration and write a report containing Application: booking-api and Status: ready. Read it back and print it.

## Acceptance criteria

The report is written in the solution directory as UTF-8 and its two lines are printed. A missing config prints an error and exits nonzero.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
