# Day 17 challenge — Java ArrayLists

Add three applications, remove index one, then print the remaining names and size.

## Acceptance criteria

booking-api and catalog-api remain in insertion order; size is two.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
