# Day 09 challenge — Methods

Create three methods named `startDeployment()`, `runSecurityScan()`, and `completeDeployment()`. Call them from `main()`.

## Acceptance criteria

Declare all three named methods and call them in the requested order.

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
