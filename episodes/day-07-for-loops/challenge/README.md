# Day 07 challenge — For Loops

Create an array of five application names and print each application using a loop.

## Acceptance criteria

Print each of five applications exactly once, in array order.

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
