# Day 29 challenge — Git & GitHub for Java Developers

In a scratch repository, commit the baseline program, create a lesson-29 branch, change DEV to QA, inspect the diff, and commit the change.

## Acceptance criteria

History contains a baseline and a QA change. git status is clean after committing, and generated .class files are ignored.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons. Install Git. A GitHub account is only needed for the optional remote step.

Run from that working folder:

```sh
javac Main.java
java Main
```

Follow the Git scratch-workflow commands in the lesson. Do not initialize another Git repository within the course clone.
