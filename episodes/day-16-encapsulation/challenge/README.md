# Day 16 challenge — Java Encapsulation

Add getReplicas(). Scale to five, attempt zero, and print both results plus the final count.

## Acceptance criteria

The valid update returns true; zero returns false; final replicas remain five.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
