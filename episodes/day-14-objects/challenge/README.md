# Day 14 challenge — Java Objects & References

Create inventory-api and notification-api objects. Set replicas to two and four. Change only inventory-api to five and print both.

## Acceptance criteria

The final replica counts are five and four, showing independent objects. Do not use one object for both references.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
