# Day 15 challenge — Java Constructors

Add an overloaded constructor Application(String name) that delegates to the full constructor with DEV and one replica.

## Acceptance criteria

One-argument creation produces DEV and one replica; full creation preserves the provided QA and three replicas.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
