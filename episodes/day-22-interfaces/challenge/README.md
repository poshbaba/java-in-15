# Day 22 challenge — Java Interfaces

Add DatabaseMigration implementing Deployable. Run a WebApplication and DatabaseMigration through a Deployable array.

## Acceptance criteria

Both operations print their own messages through the same interface contract.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
