# Day 12 challenge — Java Method Overloading

Add deploy(String application, String environment, int replicas). Delegate the two-argument overload to it with one replica.

## Acceptance criteria

The convenience overload prints one replica; the explicit call prints three. Both use one shared implementation.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
