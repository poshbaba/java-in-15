# Day 11 challenge — Java Method Scope & Local Variables

Create addReplica(int replicas) that returns replicas + 1. Store its result in main and print the count before and after.

## Acceptance criteria

Before is 3; after is 4. Explain why calling the method without assigning its result leaves the original int unchanged.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
