# Day 21 challenge — Java Inheritance & Overriding

Add BatchApplication with an overridden deploy() message. Put a WebApplication and BatchApplication into an Application array and call deploy on each.

## Acceptance criteria

Two distinct implementation messages print in array order through Application references.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
