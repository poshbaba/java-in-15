# Day 19 challenge — Java Exceptions & Validation

Validate that total replicas is positive and healthy replicas is between zero and total. Calculate 70.0 for (10, 7).

## Acceptance criteria

Valid input returns 70.0. Calls with (0, 0), (10, -1), or (10, 11) throw IllegalArgumentException. The normal solution run remains successful.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
