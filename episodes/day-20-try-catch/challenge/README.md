# Day 20 challenge — Java Try/Catch & Safe Execution

Process totals {10, 0, 5} with five healthy replicas. Catch invalid totals per item so the third check still runs.

## Acceptance criteria

Print 50.0%, the error for zero total, then 100.0%, in that order.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
