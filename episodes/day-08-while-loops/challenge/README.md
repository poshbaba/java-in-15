# Day 08 challenge — While Loops

Simulate a health check that retries up to five times and succeeds on the fourth attempt.

## Acceptance criteria

Use a maximum of five checks, succeed on check four, and stop after four printed attempts.

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
