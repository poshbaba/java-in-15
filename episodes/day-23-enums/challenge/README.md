# Day 23 challenge — Java Enums

Parse STG and UNKNOWN from a String array. Catch the invalid value and show an informative message.

## Acceptance criteria

STG converts successfully; UNKNOWN reports an error without terminating the program.

## Starting point

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
