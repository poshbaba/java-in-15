# Day 04 challenge — Arrays

Create an array containing five AWS services and print the first, third, and last service.

## Acceptance criteria

Create exactly five service names and print indexes 0, 2, and 4 without a loop.

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
