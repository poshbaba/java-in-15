# Day 10 challenge — Method Parameters & Return Values

Create a method that accepts the total number of pods and healthy pods, calculates the health percentage, and returns that percentage.

## Acceptance criteria

Return 70.0 for (10, 7), 100.0 for (10, 10), and 0.0 for (10, 0).

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
