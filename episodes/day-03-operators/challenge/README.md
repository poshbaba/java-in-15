# Day 03 challenge — Operators & Calculations

Calculate the percentage of healthy servers when 7 out of 10 are healthy.

## Acceptance criteria

Calculate 70.0% for seven healthy servers out of ten and explain why it is below 80%.

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
