# Day 18 challenge — Java HashMaps

Create booking-api -> DEV and payment-api -> QA, update booking-api to PROD, remove payment-api, and handle a missing catalog-api.

## Acceptance criteria

booking-api maps to PROD; size is one; missing catalog-api prints a friendly message.

Copy the entire [demo folder](../demo) to a separate working folder before editing. Keep its fixtures and POM if supplied. Java 21 JDK and the preceding lessons.

Run from that working folder:

```sh
javac Main.java
java Main
```
