# Day 05 challenge — If/Else Statements

Create deployment approval logic using these conditions:

- Health ≥ 95%: Approved
- Health ≥ 80% and < 95%: Review required
- Health < 80%: Rejected

## Acceptance criteria

Produce Approved, Review required, and Rejected at the correct boundaries.

Save your attempt as `Main.java` in a separate folder, then run:

```sh
javac Main.java
java Main
```
